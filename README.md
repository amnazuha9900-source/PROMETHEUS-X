Project Title

Open-Set Industrial Anomaly Detection with Localization, Severity & Distribution Shift.

Problem Statement

To develop an intelligent industrial inspection system that learns normal manufacturing patterns and detects unknown, rare, or unseen defects.

Objectives

1. Detect unknown industrial defects.
2. Identify and localize defective regions.
3. Estimate defect severity.
4. Detect distribution shifts.
5. Reduce false-positive predictions.

Domain

Advanced Computer Vision

Proposed Solution

An AI-based anomaly detection system that helps identify unusual patterns and defects in industrial products using computer vision.

Technologies

- Deep Learning
- Computer Vision
